# Tech News Today

A responsive and accessible tech news website built with HTML and CSS.

## Features

- Semantic HTML5 structure
- WCAG accessibility improvements
- Responsive layout
- Keyboard-friendly navigation
- Modern UI design
- Accessible images and navigation

## Technologies Used

- HTML5
- CSS3

## Accessibility

This project includes:
- Skip navigation link
- ARIA labels
- Semantic landmarks
- Responsive images
- Keyboard focus improvements
